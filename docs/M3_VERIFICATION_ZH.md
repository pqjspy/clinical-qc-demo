## 4. 自动回归

```bash
.venv/bin/python -m unittest discover -s tests -q
```

实际通过100项：85项原M1/M2测试 + 15项M3接口/存储测试。M3模型响应为明确标注的测试替身，用于稳定验证软件，不用于证明Qwen效果。

覆盖要点：

- 无参考答案目录仍可执行完整模拟流程。
- 固定输入/知识快照；原结果与摘要在复核后不变。
- SQLite阻止覆盖/删除初判、复核、审计、已发布版本。
- 角色矩阵、伪造actor、跨站Origin、CSRF、未登录访问。
- 幂等重复提交、过期复核版本冲突、同一时刻只运行一个模型任务。
- 人工状态/L3/风险/判定一致性；缺理由、非法L3、不勾核验声明拒绝。
- 审核与审计同事务，审计失败全部回滚。
- 草稿不影响推理、发布保留旧运行、发布失败回滚、旧草稿不能覆盖新发布。
- 模型失败/服务中断不当正常结果，不自动重跑；失败不能一键确认。
- 修改原文必须另存新编号。

前端TypeScript检查与Vite构建通过。依赖已记录在Python锁定清单与npm lockfile。测试运行有Starlette针对httpx测试适配器的弃用提示；当前已验证版本仍通过，不影响应用运行，未来升级应一起升级并回归验证。
