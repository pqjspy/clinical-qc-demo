## 常见追问的简短回答

- **为什么不用一个ChatGPT提示词？** 可以作为实验基线，但版本、规则计算、引用、权限和修改历史仍要由系统管理；当前选本地Qwen满足本地演示要求。
- **训练了吗？** 没有。本轮是预训练指令模型+提示词+规则；不能保证微调一定大涨分。先分类错误类型和补独立数据，再比较方案。
- **F1高就能上线吗？** 不能，还要看高风险漏报、未决/误转交、语义证据、真实数据分布和业务验收。
- **为什么只支持有限语法？** 这是当前原型的能力边界；有利于暴露不确定性，但限制真实语言覆盖，不应宣传为通用医院系统。
